# SvgLiveEditor

SvgLiveEditor یک برنامهٔ دسکتاپ متن‌باز برای ویندوز است که ویرایش کد SVG/XML و مشاهدهٔ هم‌زمان نتیجه را فراهم می‌کند. مرحلهٔ ۱ نسخهٔ ۰٫۱۰٫۰ انتخاب چندگانهٔ محدود، حرکت اتمی چند شیء، Group/Ungroup محافظه‌کارانه، هم‌ترازی/توزیع و snapping اختیاری را بر پایهٔ پایدار و دارای تأیید ارائهٔ مرحلهٔ ۰ اضافه می‌کند. متن دقیق UTF-8، از جمله فارسی، تنها منبع حقیقت باقی می‌ماند.

مخزن: [github.com/Mammad3861/svg-live-editor](https://github.com/Mammad3861/svg-live-editor)

## تصویر برنامه

> محل تصویر — پس از نخستین بازبینی رابط کاربری در ویندوز، تصویر برنامه افزوده می‌شود.

## امکانات

- دو زبانهٔ بومی **Layers** و **Structure** از یک فهرست کد اعتبارسنجی‌شده استفاده می‌کنند. Layers اثرهای دیداری و `<g>`های تودرتو را با عنصر جلویی در ردیف بالاتر نشان می‌دهد و definitions را پنهان می‌کند؛ Structure سلسله‌مراتب کامل XML را نگه می‌دارد. کلیک عادی یک مورد را انتخاب می‌کند، `Ctrl`+کلیک ردیف را اضافه/حذف می‌کند و `Shift`+کلیک یک بازهٔ پیوسته و محدود را فقط در همان ظرف هم‌والد و آشکار انتخاب می‌کند؛ در Preview نیز `Shift`+کلیک انتخاب را تغییر می‌دهد. حداکثر ۱۲۸ مورد با شناسه‌های مبهم و وابسته به revision نگه‌داری می‌شوند و یک مورد primary/anchor با Properties و Source هماهنگ می‌ماند، بدون اینکه AvalonEdit وانمود کند چند بازهٔ جدا را نمایش می‌دهد.
- کنترل فشردهٔ **Add** و منوهای زمینهٔ Layers/Structure فقط شش نوع ثابت و متعلق به برنامه، یعنی `rect`، `circle`، `ellipse`، `line`، `text` و `g` خالی را با هندسهٔ محدود و برگرفته از canvas/viewBox امن می‌سازند. کاربر مقصد را صریحاً میان ریشهٔ SVG و گروه/زمینهٔ هم‌سطح انتخاب‌شده تعیین می‌کند و برنامه میان آن‌ها حدس نمی‌زند. عنصر تازه بلافاصله در هر دو درخت و Properties انتخاب می‌شود و یک مرحله Undo است. F2 یا **Rename Layer** فقط ویژگی اختیاری و متعلق به source یعنی `data-name` را ویرایش می‌کند؛ فارسی، انگلیسی، متن ترکیبی، فاصله و نشانه‌گذاری امن پذیرفته می‌شود و SVG `id` فنی و referenceها تغییر نمی‌کنند. خالی‌کردن فیلد `data-name` را حذف می‌کند. `Ctrl+D` انتخاب را تکثیر می‌کند و Delete یا Backspace هنگام فوکوس Layers، Structure، Preview یا سطح غیرقابل‌ویرایش Properties انتخاب واجد شرایط را حذف می‌کند؛ این میان‌برها هرگز رفتار ویرایش متن در Source، فیلدهای Properties، ComboBox/فونت قابل‌ویرایش، ویرایش Rename یا ترکیب IME را تصاحب نمی‌کنند.
- بازرس ویژگی‌ها برای مشخصه‌های امن متداول، هندسهٔ شکل‌ها و تایپوگرافی متن، همراه با دکمهٔ دیداری و قابل‌فوکوس راهنما، tooltip کوتاه و راهنمای screen reader برای ویژگی‌های رایج SVG. ComboBox قابل‌ویرایش `font-family` فقط نام تمیز و بدون کوتیشن خانوادهٔ اصلی را نشان می‌دهد؛ tooltip و کد SVG کل stack اعتبارسنجی‌شدهٔ fallback را حفظ می‌کنند. انتخاب یا تایپ خانوادهٔ اصلی فقط همان ورودی را جایگزین می‌کند و نام‌های لازم به‌طور امن کوتیشن‌گذاری می‌شوند. تغییر ثبت‌شده با باقی‌ماندن فوکوس در Properties نیز با `Ctrl+Z`/`Ctrl+Y` قابل بازگشت است؛ تایپ ثبت‌نشده Undo/Redo محلی استاندارد فیلد را حفظ می‌کند، کل XML دوباره serialize نمی‌شود و مقدار `d` مسیر همچنان فقط خواندنی است.
- ویرایشگر AvalonEdit با رنگ‌آمیزی XML، شمارهٔ خطوط، برجسته‌سازی خط جاری، Undo/Redo، جست‌وجو و جایگزینی، شکستن غیرمخرب خطوط و منوی راست‌کلیک متعلق به برنامه برای Undo، Redo، Cut، Copy، Paste، Delete و Select All. راست‌کلیک روی متن انتخاب‌شده، انتخاب را حفظ می‌کند. برای تغییر وضعیت Word Wrap از `Alt+Z` یا `Ctrl+Alt+W` استفاده کنید.
- گالری قالب بومی WPF و قابل استفاده با صفحه‌کلید در مسیر **File > New from Template** با میان‌بر `Ctrl+Alt+N`. پنج قالب Blank Canvas، App Icon، Social Card، Flow Diagram و Persian/RTL همگی با همان اعتبارسنج سخت‌گیرانه بررسی می‌شوند و به‌صورت سند جدا، Modified و نیازمند Save As باز می‌شوند؛ منبع جاسازی‌شده هرگز بازنویسی نمی‌شود. متن‌های قالب دارای فرادادهٔ منفعل و صریح BiDi هستند: قالب فارسی از `direction="rtl"`، مقدار `unicode-bidi="embed"` و `text-anchor="start"` مناسب RTL استفاده می‌کند و جای‌نگهدارهای خنثی بدون directional override از `unicode-bidi="plaintext"` استفاده می‌کنند.
- پیش‌نمایش خودکار با تأخیر تقریبی ۳۰۰ میلی‌ثانیه و دکمهٔ بازخوانی دستی.
- بزرگ‌نمایی، کوچک‌نمایی، بازنشانی و تطبیق تصویر با فضای پیش‌نمایش روی پس‌زمینهٔ شطرنجی ثابت. حالت بزرگ‌نمایی در اجرای بعدی بازیابی می‌شود؛ `Ctrl` همراه چرخ ماوس در نقطهٔ نشانگر زوم می‌کند، چرخ عادی پیمایش عمودی و `Shift` همراه چرخ پیمایش افقی را انجام می‌دهد.
- ابزار Select با میان‌بر `V` انتخاب را با Layers/Structure، Properties و start tag مورد primary هماهنگ می‌کند. انتخاب چندگانهٔ امن از `rect`، `circle`، `ellipse`، `line` و `<text>` مستقیمِ اندازه‌گیری‌شده با Drag یا کلیدهای جهت (۱ واحد و با `Shift` ده واحد) یکجا حرکت می‌کند. اگر یک عضو stale، قفل، مبهم یا پشتیبانی‌نشده باشد کل عملیات رد می‌شود و فقط زیرمجموعهٔ امن حرکت نمی‌کند. outlineهای primary/secondary متعلق به میزبان حرکت پیشنهادی را نشان می‌دهند و هر رهاسازی یا Nudge فقط یک Undo می‌سازد. handleهای Resize عمداً فقط برای انتخاب تک‌عنصری باقی می‌مانند و source در هر حرکت pointer بازنویسی نمی‌شود.
- منوی **Arrange** علاوه بر ترتیب هم‌والد، **Group** با `Ctrl+G`، **Ungroup** محافظه‌کارانه با `Ctrl+Shift+G`، شش فرمان هم‌ترازی و توزیع افقی/عمودی را ارائه می‌کند. Group فقط ۲ تا ۱۲۸ sibling جاری و پیوسته را زیر یک والد SVG/گروه می‌پذیرد، یک wrapper واقعی `<g>` در Source می‌نویسد و گروه قابل‌بازشدن جدید را primary می‌کند. Ungroup فقط `<g>` خنثی، غیرخالی، بدون attribute و بدون animation هدف‌گیرندهٔ گروه را باز می‌کند. هر دو میان‌بر از Preview، Layers، Structure و بخش‌های غیرقابل‌ویرایش پنجره اجرا می‌شوند و رد شدن فرمان دلیل دقیق را در نوار وضعیت نشان می‌دهد. هم‌ترازی از bounds دیداری اعتبارسنجی‌شده و لبه/مرکز محدودهٔ ترکیبی استفاده می‌کند؛ توزیع دو شیء بیرونی مرتب‌شده بر پایهٔ هندسه را ثابت نگه می‌دارد و فاصله‌های دیداری را برابر می‌کند. همهٔ اعضا باید قابل‌اندازه‌گیری، قابل‌حرکت، باز و در یک دستگاه مختصات هم‌والد باشند؛ هر فرمان یک ویرایش حداقلی و یک Undo است و no-op ویرایش نمی‌سازد. Drag در Layers همچنان مسیر صریح before/after/inside برای تغییر والد است و از Group جدا می‌ماند.
- گزینهٔ **View > Snap to objects** به‌طور پیش‌فرض روشن و برای کاربر ذخیره می‌شود. هنگام Move امن، فقط لبه/مرکز siblingهای نمایان، باز و قابل‌حرکت و مرکز canvas/viewBox تا آستانهٔ ۴ پیکسل CSS هدف هستند. کمترین اصلاح انتخاب می‌شود و tie مبهم یا sibling هم‌اندازهٔ کل canvas نادیده گرفته می‌شود. آستانه با Fit/زوم دستی به واحد SVG نگاشت می‌شود و حداکثر یک راهنمای متعلق به میزبان در هر محور دیده می‌شود. راهنما بدون تغییر source پاک می‌شود و وارد PNG نمی‌شود.
- هر ردیف Layers کنترل نمایش و قفل متعلق به برنامه دارد. تغییر نمایش فقط برای عنصر بدون مالکیت مبهم، `display="none"` استاندارد می‌افزاید و آن را فقط تا زمانی حذف می‌کند که برنامه بداند این حالت در نشست جاری ساخته شده است. `display`، `visibility`، style یا animation نوشته‌شده توسط کاربر هرگز بازنویسی نمی‌شود. قفل فقط در نشست جاری است و ساخت، تکثیر، حذف، Group/Ungroup، Move، Resize، Nudge، layout، Arrange، reorder/reparent، Opacity و Properties را محافظت می‌کند، اما Source همچنان قابل ویرایش است.
- بخش Properties کنترل اختصاصی **Opacity** از ۰ تا ۱۰۰ درصد دارد. حرکت Slider تا زمان رها کردن فقط مقدار پیشنهادی رابط را تغییر می‌دهد و سپس یک ویرایش source ثبت می‌شود؛ مقدار تایپی با Enter یا خروج فوکوس ثبت و با Escape برگردانده می‌شود. نبودن `opacity` معادل ۱۰۰٪ است و ثبت ۱۰۰٪ فقط همین ویژگی اختیاری را حذف می‌کند، بدون تغییر `fill-opacity` یا `stroke-opacity`. opacity متعلق به style، مقدار malformed، animation، transform یا effectهای حذف‌شده کنترل را به‌صورت محافظه‌کارانه غیرفعال می‌کنند.
- حالت آشکار Pan در نوار ابزار؛ `H` آن را روشن/خاموش و `Escape` حرکت جاری را لغو و از Pan خارج می‌کند. وقتی محتوا از viewport بزرگ‌تر است، می‌توان با کشیدن چپ در حالت Pan، Space همراه کشیدن چپ یا دکمهٔ میانی جابه‌جا شد. حالت Pan و Space+Drag بر انتخاب و اشتراک تصویر اولویت دارند.
- کپی کامل تصویر معتبر و شفاف به‌صورت PNG از مسیر **Preview > Copy Preview as PNG**، دکمهٔ **Copy Image**، `Ctrl+Shift+C`، فشردن `Ctrl+C` هنگامی که پیش‌نمایش فوکوس دارد، یا منوی ثابت راست‌کلیک پیش‌نمایش. تمام اثر هنری، نه فقط بخش دیده‌شدهٔ viewport، کپی می‌شود و زوم یا وضعیت سند تغییر نمی‌کند.
- با `Ctrl` همراه کشیدن چپ روی اثر SVG رندرشده می‌توان PNG را مستقیماً به Explorer، Telegram Desktop، Paint یا مقصدهای دیگر ویندوز کشید؛ `Alt`+کشیدن چپ فعلاً به‌عنوان alias سازگار باقی می‌ماند. کشیدن چپ عادی عنصر پشتیبانی‌شدهٔ انتخابی را حرکت می‌دهد، Shift+Click انتخاب چندگانه را تغییر می‌دهد و Space+کشیدن چپ یا دکمهٔ میانی Pan می‌کند. شروع از فضای شطرنجی، ترکیب modifierها، کلیک بدون عبور از آستانهٔ Drag ویندوز یا استفاده از حرکت Pan خروجی ایجاد نمی‌کند. کنترل آشکار **Drag Image** به‌عنوان راه دسترس‌پذیر جایگزین باقی می‌ماند. هر دو مسیر از همان رندر کامل و اعتبارسنجی‌شده استفاده می‌کنند و فایل واقعی PNG همراه با قالب‌های PNG/Bitmap و شفافیت را ارائه می‌دهند.
- کپی دقیق تمام کد ویرایشگر از مسیر **Edit > Copy Entire SVG Source** یا `Ctrl+Alt+C`. پایان خط‌ها، متن فارسی، XML نامعتبر، caret، انتخاب و وضعیت Modified بدون تغییر می‌مانند؛ `Ctrl+C` عادی هنگامی که ویرایشگر کد یا فیلد ویژگی در بازرس فوکوس دارد فقط متن انتخاب‌شدهٔ همان قسمت را کپی می‌کند.
- New، Open، Save، Save As، Exit و رها کردن یک فایل محلی `.svg` یا `.txt` در تمام سطح پنجره. پوشش **Drop SVG or TXT to open** روی Source، بازرس سند، Properties و Live Preview دیده می‌شود. پیش از جایگزینی همان هشدار تغییرات ذخیره‌نشده اجرا می‌شود و Cancel سند جاری را تغییر نمی‌دهد. فایل با UTF-8 سخت‌گیرانه خوانده و به ۱۰٬۰۰۰٬۰۰۰ بایت محدود می‌شود.
- آخرین سند نام‌داری که با موفقیت باز یا ذخیره شده است، به‌طور پیش‌فرض در اجرای بعدی دوباره باز می‌شود. گزینهٔ قابل‌علامت‌گذاری این رفتار و مسیر کامل فایل فقط در تنظیمات LocalAppData کاربر جاری ذخیره می‌شوند؛ مسیر گم‌شده، غیرقابل‌دسترسی یا پشتیبانی‌نشده بدون خطا به سند خوش‌آمدگویی برمی‌گردد.
- بازیابی خرابی به‌طور پیش‌فرض فعال است. متن دقیق UTF-8، از جمله XML نامعتبر و متن فارسی، پس از تأخیر کوتاه به‌صورت snapshot اتمی با شناسهٔ تصادفی فقط در `%LocalAppData%\SvgLiveEditor\Recovery` ذخیره می‌شود. پیش از باز کردن آخرین سند، پنجرهٔ Restore، Discard یا Skip نمایش داده می‌شود. Restore داده را در حافظه و با وضعیت Modified باز می‌کند و هرگز فایل اصلی را بازنویسی نمی‌کند. snapshot یکسان با فایل اصلی بدون پیام حذف می‌شود. نگه‌داری به ۷ روز، ۱۰ فایل و ۱۰۰٬۰۰۰٬۰۰۰ بایت محدود است.
- گزینهٔ **File > Auto Save** به‌طور پیش‌فرض خاموش است و تنظیم آن برای کاربر جاری حفظ می‌شود. فقط فایل موجود و نام‌دار `.svg` یا `.txt` که به‌صورت دستی باز یا ذخیره شده باشد، دو ثانیه پس از آخرین ویرایش و تنها در صورت پذیرش توسط اعتبارسنج سخت‌گیرانه با UTF-8 دقیق و جایگزینی اتمی ذخیره می‌شود. XML نامعتبر، فایل اصلی گم‌شده/فقط‌خواندنی/غیرقابل‌دسترسی، reparse point، مسیر شبکه، drive پشتیبانی‌نشده یا شکست سیاست باعث توقف Auto Save بدون تغییر فایل اصلی می‌شود؛ snapshot بازیابی ادامه دارد. سند بدون نام و قالب همچنان به Save As نیاز دارد.
- هشدار تغییرات ذخیره‌نشده پیش از بستن یا جایگزین کردن سند.
- خواندن UTF-8 معتبر و ذخیرهٔ UTF-8 بدون BOM، بدون بازآرایی کد کاربر.
- اعتبارسنجی امن XML همراه با پیام، شمارهٔ خط و ستون.
- نمونهٔ کاملاً جدید و امن انگلیسی/فارسی به‌عنوان محتوای سند تازه.
- نماد اختصاصی و کاملاً جدید با اندازه‌های گوناگون که در فایل اجرایی، نوار عنوان، نوار وظیفه و Alt+Tab جاسازی شده است.

مسیر تعامل قابل اعتماد، از جمله اندازه‌گیری متن انگلیسی و فارسی با Chromium، تغییر اندازهٔ واقعی و پیام‌های وابسته به revision/selection، با آزمون یکپارچه پوشش داده شده است. انتخاب چندگانه در Preview/Layers، Multi-drag/Nudge، Group/Ungroup، همهٔ فرمان‌های هم‌ترازی/توزیع، راهنمای snap در Fit/زوم دستی، authoring، reparent، قفل، Resize، Opacity، فونت، Drag/Drop، Ctrl+Wheel، Ctrl+C وابسته به فوکوس، touchpad و Pan باید روی دستگاه هدف هر انتشار نیز تأیید شوند.

ویرایشگر کد XML عمداً چپ‌به‌راست باقی می‌ماند تا نشانه‌گذاری و ساختار tagها قابل پیش‌بینی باشد. متن و نشانه‌گذاری فارسی از نظر منطقی و به‌صورت UTF-8 دقیق حفظ می‌شود، اما حرکت caret و جای‌گیری دیداری glyphهای ترکیبی RTL/LTR در خود ویرایشگر تابع محدودیت‌های BiDi در AvalonEdit/WPF است. پیش‌نمایش SVG کد را دقیقاً همان‌گونه که نوشته شده رندر می‌کند: ویژگی‌های صریح `direction`، `unicode-bidi` و `text-anchor` چیدمان را تعیین می‌کنند و برنامه متن فارسی را بازنویسی یا دارای نویسهٔ جهت نامرئی نمی‌کند.

## مدل امنیتی و محدودیت‌ها

همهٔ فایل‌های بازشده غیرقابل اعتماد فرض می‌شوند. DTD، تعریف entity و دسترسی entity خارجی ممنوع است. عنصر ریشه باید `svg` با فضای نام استاندارد باشد. اسکریپت، رخدادهای inline، `foreignObject`، محتوای فعال، processing instruction، عنصر `<style>`، لینک و منبع غیرمحلی رد می‌شوند.

SVG معتبر به UTF-8/Base64 تبدیل و فقط به‌صورت data image در HTML نمایش داده می‌شود؛ کد خام SVG هرگز داخل HTML میزبان قرار نمی‌گیرد. CSP سخت‌گیرانه فقط یک اسکریپت ثابت متعلق به برنامه را با هش دقیق SHA-256 مجاز می‌کند. ورودی pointer هیچ SVG ID نوشته‌شده توسط کاربر را حمل نمی‌کند؛ .NET hit testing را انجام می‌دهد و حداکثر ۱۲۸ انتخاب مبهم و وابسته به revision نگه می‌دارد. پیام overlay از میزبان به صفحه schema دقیق و محدود برای هندسهٔ ساخته‌شده توسط میزبان، یک primary و حداکثر دو راهنمای موقت دارد؛ پیام دلخواه برای انتخاب چندگانه یا ویرایش source پذیرفته نمی‌شود. Resize همچنان به یک selection/gesture ID تصادفی جاری و وضعیت فیزیکی دکمه محدود است. Copy Preview فقط تصویر جداشده را روی canvas شفاف می‌کشد؛ outline، handle و guide وارد PNG نمی‌شوند. زوم سند مرورگر ۱۰۰٪ می‌ماند و script کاربر، host object، پیام دلخواه، مجوز، دانلود، popup، navigation/resource خارجی، ابزار توسعه و منوی مرورگر مسدود هستند. کد نامعتبر آخرین Preview معتبر را نگه می‌دارد و ویرایش دیداری را غیرفعال می‌کند.

اندازهٔ PNG برای Clipboard و Drag Image از width/height ذاتی SVG یا، در نبود آن، از نسبت و ابعاد `viewBox` گرفته می‌شود. نسبت تصویر حفظ و خروجی به حداکثر ۴۰۹۶ پیکسل در هر ضلع و ۸٬۰۰۰٬۰۰۰ پیکسل در مجموع (حدود ۳۲ مگابایت RGBA فشرده‌نشده) محدود می‌شود. تصویرهای بزرگ پیش از تخصیص bitmap کوچک می‌شوند. اگر کد جاری نامعتبر باشد، اشتراک‌گذاری عمداً آخرین پیش‌نمایش معتبر را به کار می‌برد و این موضوع را اعلام می‌کند؛ هنگام انتظار برای اعتبارسنجی نیز نتیجه به‌عنوان آخرین پیش‌نمایش اعتبارسنجی‌شده معرفی می‌شود. اگر پیش‌نمایش معتبر و قابل‌مشاهده‌ای وجود نداشته باشد، فرمان غیرفعال است یا خطایی غیرمخرب نمایش می‌دهد.

برای سازگاری Drag در ویندوز، PNG اعتبارسنجی‌شده با نام تصادفی متعلق به برنامه در `%LocalAppData%\SvgLiveEditor\DragOut` نوشته می‌شود و کد SVG هرگز کنار آن ذخیره نمی‌شود. فایل Drag لغوشده در صورت امن بودن حذف می‌شود. فایل Drag موفق برای برنامه‌هایی که با تأخیر آن را می‌خوانند موقتاً باقی می‌ماند؛ پاک‌سازی هنگام شروع برنامه، پیش از ساخت Drag بعدی و هر شش ساعت اجرا می‌شود. فایل‌های مدیریت‌شدهٔ قدیمی‌تر از ۲۴ ساعت حذف می‌شوند و پوشه حداکثر ۲۰ فایل و ۲۰۰٬۰۰۰٬۰۰۰ بایت نگه می‌دارد. شکست پاک‌سازی مانع اجرای برنامه نمی‌شود.

بازیابی از رندر پیش‌نمایش جدا است. snapshot فقط در پوشهٔ ثابت کاربر جاری با شناسهٔ تصادفی ساخته‌شده توسط برنامه و جایگزینی اتمی در همان پوشه نوشته می‌شود. بارگذار فقط schema نسخه‌دار دقیق را می‌پذیرد و تطابق شناسه با نام فایل، metadata، مسیر نرمال و پشتیبانی‌شده، اندازهٔ متن و SHA-256 را بررسی می‌کند؛ reparse point و رکورد خراب یا دست‌کاری‌شده رد می‌شود و مسیر ذخیره‌شده هرگز برای خواندن متن snapshot دنبال نمی‌شود. مسیر اصلی فقط در صورت امن و موجود بودن به‌عنوان ارتباط سند استفاده می‌شود. Auto Save بایت‌های دقیق UTF-8 را کنار فایل محلی واجد شرایط آماده می‌کند و پیش از جایگزینی اتمی، سیاست مسیر و session/revision دقیق سند را دوباره بررسی می‌کند؛ فایل اصلی گم‌شده را دوباره نمی‌سازد.

Layers و Structure فقط از کدی ساخته می‌شوند که همان اعتبارسنج امن آن را پذیرفته باشد. هر دو projection بومی WPF از spanهای دقیق فهرست‌شده هستند و هیچ دسترسی DOM به SVG اضافه نمی‌کنند. ساخت فقط شش نوع متعلق به برنامه، یک مقصد صریح و پیش‌فرض‌های محدود میزبان را می‌پذیرد. نام دوستانه span و revision دقیق جاری را دوباره بررسی می‌کند و فقط ویژگی محدود و XML-safe یعنی `data-name` را تغییر می‌دهد؛ ویرایش `id` فنی همچنان عملیات محافظه‌کارانهٔ جداگانه در Properties است. کلیدهای authoring در Preview فقط با پیام app-owned دارای schema دقیق و وابسته به token ناوبری و revision از مرز WebView عبور می‌کنند. Duplicate برای IDها نام یکتای قطعی می‌سازد و referenceهای محلی تحلیل‌شدهٔ `href`/`url(#id)` در subtree کپی‌شده را بازنویسی می‌کند؛ اگر هدف گم‌شده یا مبهم باشد عملیات fail closed است. Delete و انتقال میان والدها span جاری، قفل، ancestry، مرز definitions، revision و زمینهٔ معنایی را دوباره بررسی و فقط یک ویرایش حداقلی اعمال می‌کنند. انتقال میان والدها هنگامی که presentation یا namespace موروثی می‌تواند تغییر کند عمداً رد می‌شود. همهٔ ویرایش‌های authoring، ویژگی، opacity، visibility، Arrange، Drag در Layers یا جابه‌جایی دیداری مستقیماً سند AvalonEdit را تغییر می‌دهند و سپس همان مسیر اعتبارسنجی، Auto Save، Recovery و پیش‌نمایش اجرا می‌شود. برای `<text>` ویژگی‌های `x`، `y`، `font-family`، `font-size`، `font-weight`، `font-style`، `fill`، `direction`، `unicode-bidi` و `text-anchor` همراه با کنترل درصدی opacity ارائه می‌شوند. فونت دانلود، جاسازی یا همراه برنامه بسته‌بندی نمی‌شود، مقدارهای bidi override عمداً ارائه نمی‌شوند و هیچ DOM متعلق به SVG در اختیار WebView2 یا JavaScript قرار نمی‌گیرد.

این نسخهٔ MVP عمداً فقط زیرمجموعه‌ای امن و محدود از SVG را پشتیبانی می‌کند و همهٔ قابلیت‌های معتبر SVG را نمایش نمی‌دهد. تصویر، فونت و استایل خارجی، data resource، لینک، `<style>`، `foreignObject`، اسکریپت و event handler قابل پیش‌نمایش نیستند. چون خروجی ابزارهای مختلف یکسان نیست، باز شدن همهٔ SVGهای ساخته‌شده با ابزارهایی مانند Adobe Illustrator یا Inkscape تضمین نمی‌شود. جزئیات بیشتر در [docs/security-model.md](docs/security-model.md) آمده است.

## محدودهٔ فعلی

مرحلهٔ ۱ نسخهٔ ۰٫۱۰٫۰ انتخاب چندگانهٔ محدود، حرکت/Nudge اتمی چند شیء، Group/Ungroup محافظه‌کارانه، شش حالت هم‌ترازی، توزیع با فاصلهٔ برابر و snapping اختیاری شیء/مرکز canvas را پیاده می‌کند و پایهٔ latest-wins و source-authoritative مرحلهٔ ۰ را حفظ می‌کند. Properties و Source همچنان از یک مورد primary پیروی می‌کنند. Resize انتخاب چندگانه، transform/rotation دلخواه، حرکت یا Resize path، حرکت زندهٔ خود اثر در هر pointermove، ویرایش inline متن، ruler، guide دستی و پیشنهاد هوشمند پیشرفته در این مرحله نیستند. عملیات ناامن یا مبهم fail closed است. **خروجی صریح فایل** PNG/PDF، نصب‌کننده و به‌روزرسانی خودکار نیز ارائه نمی‌شود.

جای‌گذاری دقیق before/after/inside میان والدها اکنون از سطح Drag در Layers استفاده می‌کند. فرمان **Move to SVG Root (Front)** مسیر خروج از گروه با صفحه‌کلید را فراهم می‌کند؛ انتخاب‌گر مقصد با صفحه‌کلید برای انتقال به داخل یا میان گروه‌ها یک بهبود دسترس‌پذیری آینده باقی می‌ماند.

| دستهٔ Preview/Layers | رفتار مرحلهٔ ۱ نسخهٔ ۰٫۱۰٫۰ |
| --- | --- |
| `rect`، `circle`، `ellipse`، `line` | در صورت سازگاری هندسه و ancestorها با قواعد محافظه‌کارانهٔ واحد، transform و effect قابل انتخاب، جابه‌جایی و تغییر اندازه هستند. مستطیل/بیضی هشت handle، دایره چهار handle شعاعی و خط دو handle انتهایی دارد. |
| `<text>` ساده و مستقیم | پس از اندازه‌گیری محدود و قابل اعتماد متن انتخاب و جابه‌جا می‌شود. اندازهٔ متن با فیلد `font-size` در Properties و مقدار مثبت بدون واحد یا `px` ویرایش می‌شود. |
| `path`، `polygon`، `polyline` | هرگز جابه‌جا نمی‌شوند. اگر bounds محافظه‌کارانه و امن در دسترس باشد، فقط برای بازرسی انتخاب می‌شوند؛ در غیر این صورت دلیل کوتاه fail-closed نمایش داده می‌شود. عنصر پشتیبانی‌نشدهٔ topmost هرگز اجازهٔ click-through به اثر زیرین نمی‌دهد. |
| `g` | گروه موجود/ساخته‌شده قابل‌بازشدن، reorder و reparent می‌ماند. Group فقط انتخاب پیوستهٔ هم‌والد را wrap می‌کند. Ungroup فقط wrapper غیرخالیِ بدون attribute یا animation هدف‌گیرندهٔ گروه را حذف می‌کند و در غیر این صورت دلیل رد امن را نشان می‌دهد. Preview همچنان DOM گروه را آشکار نمی‌کند. |
| `tspan`، `textPath` و متن تودرتو یا پیچیده | جابه‌جایی دیداری ندارد و از Source و Inspector قابل ویرایش می‌ماند. |
| محتوای transformشده، clipشده، maskشده، filterشده، متحرک، مخفی، malformed یا دارای واحد پشتیبانی‌نشده | جابه‌جایی دیداری ندارد و محتوای topmost مبهم برای انتخاب عنصر زیرین دور زده نمی‌شود. |
| `defs`، gradient، marker، pattern و محتوای تعریفی | به‌عنوان اثر مستقل و قابل انتخاب در Preview در نظر گرفته نمی‌شود. |

Resize handle متن و انتخاب چندگانه عمداً بخشی از مرحلهٔ ۱ نسخهٔ ۰٫۱۰٫۰ نیست؛ اندازهٔ متن از فیلد معتبر `font-size` تغییر می‌کند. کمینهٔ اندازهٔ شکل ۰٫۰۱ واحد SVG است و عبور از لبهٔ ثابت به‌جای وارونه‌کردن عنصر در همین مقدار clamp می‌شود.

[نقشهٔ راه رسمی](docs/roadmap.fa.md) قابلیت‌های عرضه‌شده، نیازهای ضروری پیش از v1 و ایده‌های اختیاری پس از v1 را جدا می‌کند. این متن راهنمای برنامه‌ریزی است، نه وعده یا زمان‌بندی قطعی. Auto Save عمداً فقط برای SVG معتبر فعال است و جایگزین کنترل نسخه یا پشتیبان‌گیری نیست.

## پیش‌نیازها

برای ساخت:

- Windows 10 یا Windows 11
- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)، نسخهٔ `10.0.302` یا feature band جدیدتر سازگار با .NET 10

برای اجرا:

- Windows 10 یا Windows 11
- [Microsoft Edge WebView2 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/#download-section)

خروجی self-contained شامل .NET Desktop Runtime است؛ بنابراین کاربر فایل ZIP بسته‌بندی‌شده نیازی به نصب جداگانهٔ .NET Desktop Runtime ندارد. این بسته WebView2 Evergreen Runtime را همراه خود ندارد.

نسخه‌های ثابت بسته‌ها: AvalonEdit `6.3.1.120`، Microsoft.Web.WebView2 `1.0.4078.44`، MSTest `4.3.2` و Microsoft.NET.Test.Sdk `18.8.1`.

## انتشار win-x64

```powershell
dotnet publish src/SvgLiveEditor/SvgLiveEditor.csproj --configuration Release --runtime win-x64 --self-contained true --property:PublishProfile=win-x64
```

خروجی در `dist/win-x64` قرار می‌گیرد. برای انتشار، ممیزی بسته و ساخت فایل‌های ZIP و SHA-256 نسخه‌دار در سیستم محلی:

```powershell
./scripts/Publish-WinX64.ps1 -Version 0.10.0
```

این دستور فایل‌های محلی `releases/SvgLiveEditor-v0.10.0-win-x64.zip` و `releases/SvgLiveEditor-v0.10.0-win-x64.sha256` را می‌سازد. فایل checksum برای بررسی داخلی و محلی باقی می‌ماند. اجرای محلی این دستور هیچ GitHub Release را ایجاد یا ویرایش نمی‌کند. برای پایداری WPF و وابستگی‌های بومی WebView2، trimming، ReadyToRun و single-file فعال نشده‌اند.

## انتشار خودکار در GitHub

[گردش‌کار انتشار](.github/workflows/release.yml) با push شدن یک برچسب نسخهٔ معنایی پایدار مانند `v0.10.0` به‌صورت خودکار اجرا می‌شود. این گردش‌کار را می‌توان برای یک برچسب موجود نیز دستی اجرا کرد تا فایل باینری به Release موجود افزوده شود. برچسب با دقت اعتبارسنجی می‌شود، دقیقاً همان commit دریافت می‌شود، نسخهٔ پروژه بررسی می‌شود، restore و build در حالت Release انجام می‌شود، آزمون‌ها به‌جز `TestCategory=DesktopIntegration` اجرا می‌شوند و همان اسکریپت انتشار برای ساخت و ممیزی بسته به کار می‌رود.

فایل ZIP و فایل داخلی `.sha256` به‌عنوان artifact کوتاه‌مدت رفع اشکال در GitHub Actions نگهداری می‌شوند، اما فقط ZIP به GitHub Release جدید پیوست می‌شود. گردش‌کار checksum داخلی را پیش از upload بررسی و SHA-256 را در log و خلاصهٔ job ثبت می‌کند. Release موجود وضعیت انتشار، یادداشت‌های ویرایش‌شدهٔ دستی و دارایی‌های تاریخی نامرتبط را حفظ می‌کند و فقط ZIP هم‌نام آن جایگزین می‌شود. اگر Release متناظر وجود نداشته باشد، گردش‌کار یک Release پیش‌نویس با یادداشت‌های تولیدشدهٔ GitHub می‌سازد، در صورت وجود از برچسب پایدار قبلی استفاده می‌کند و آن را برای بازبینی دستی منتشرنشده باقی می‌گذارد.

## دریافت

فایل `SvgLiveEditor-vX.Y.Z-win-x64.zip` را از GitHub Release متناظر دریافت کنید. GitHub مقدار مورد انتظار **Digest** را مستقیماً زیر دارایی ZIP نشان می‌دهد. SHA-256 فایل دریافت‌شده را در PowerShell محاسبه و با همان Digest مقایسه کنید:

```powershell
Get-FileHash .\SvgLiveEditor-v0.10.0-win-x64.zip -Algorithm SHA256
```

پیش از اجرای `SvgLiveEditor.exe`، **تمام محتوای** ZIP را در یک پوشهٔ جدید استخراج کنید. بسته برای win-x64 به‌صورت self-contained ساخته شده و به نصب جداگانهٔ .NET نیاز ندارد. Microsoft Edge WebView2 Evergreen Runtime همچنان یک پیش‌نیاز خارجی است و باید روی رایانه نصب باشد.
